# react-native-app-functions

Expose React Native app functionality to on-device AI agents via Android AppFunctions

## Installation


```sh
npm install react-native-app-functions
```


## Usage


```js
import { multiply } from 'react-native-app-functions';

// ...

const result = multiply(3, 7);
```
